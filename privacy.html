개인정보처리방침

본 앱(wumyeonsan uploader)은 영진암(굿당TV) 채널 운영자가 직접 제작한 영상을 운영자 본인의 YouTube 채널과 Google 드라이브에 업로드하기 위한 개인용 도구입니다.

1. 수집하는 정보

앱은 운영자 본인의 Google 계정 인증 정보(접근 토큰)만 사용하며, 다른 사용자의 개인정보를 수집하지 않습니다.

2. 이용 목적

운영자 본인 채널에 영상 업로드, 본인 Google 드라이브에 영상·대본 저장에만 사용합니다.

3. 보관과 제공

인증 정보는 운영자 본인의 PC에만 저장되며 제3자에게 제공하거나 판매하지 않습니다.

4. Google API 데이터 사용

본 앱이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

5. 권한 철회

Google 계정 설정 > 보안 > 타사 앱 및 서비스에서 언제든 앱의 접근 권한을 철회할 수 있습니다.
